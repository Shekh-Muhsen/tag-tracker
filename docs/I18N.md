# Initial localization

This contribution introduces English (fallback) and Brazilian Portuguese to the shared web UI used by the server and Android WebView, including the map, login and help/consent pages. It does not yet translate Android-native settings/dialogs.

Edit the two message dictionaries in `web/static/i18n.js`. Add `data-i18n` to static labels, `data-i18n-title` to tooltips, or use `TT_I18N.t(key, {variable: value})` for dynamic status text. The language selector persists the preference in localStorage; without a saved preference, Portuguese browsers select pt-BR and others use English.

To test, switch languages on the login, map and help pages, reload, and verify static labels as well as dynamic status and popup messages. Translation does not modify API data or location history.
